# TaskFlow API

TaskFlow API is a progressive backend learning project where I am building a production-style Django REST API step by step.

As I move through the project, I will gradually add:

- Django project structure and custom user model
- PostgreSQL models, relationships, migrations, transactions and optimized queries
- Django REST Framework serializers, ViewSets, routers, filtering and pagination
- JWT authentication, permissions and user-scoped data
- Automated tests and factories
- Docker and Docker Compose
- CI/CD and production deployment
- Redis caching
- Celery background tasks and scheduled jobs
- Idempotent API operations
- Secure webhook verification
- Cleaner service boundaries and architecture documentation

The goal is not to build only a CRUD task application, but to progressively practice and demonstrate real backend engineering decisions such as security, ownership isolation, performance, testing, deployment, background processing and reliable API design.

## Status

Work in progress — features will be added phase by phase as I continue learning backend development.
